## 🔧 MANDATORY IMPLEMENTATION REQUIREMENTS

### 1. CODE QUALITY (Target: 100/100)
- TypeScript strict mode everywhere — zero `any` types
- Zero ESLint errors or warnings. Use `"plugin:@typescript-eslint/recommended"` and `"plugin:react-hooks/recommended"`
- All React state initializers must be pure (no `Date.now()` or `Math.random()` in initial state — use `0` or `''` instead, compute in handlers)
- No unused imports, variables, or parameters
- Named exports only (no default export for components)
- Modular, single-responsibility modules in `/lib`
- Use `void` prefix for floating promises inside `useEffect`
- All async functions must have proper error handling with typed catch blocks

### 2. SECURITY (Target: 100/100)

In `next.config.ts`, add ALL these security headers:
```typescript
const nextConfig: NextConfig = {
  async headers() {
    return [
      {
        source: '/(.*)',
        headers: [
          { key: 'X-Frame-Options', value: 'DENY' },
          { key: 'X-Content-Type-Options', value: 'nosniff' },
          { key: 'X-DNS-Prefetch-Control', value: 'off' },
          { key: 'Referrer-Policy', value: 'strict-origin-when-cross-origin' },
          { key: 'Permissions-Policy', value: 'camera=(), microphone=(), geolocation=()' },
          { key: 'Strict-Transport-Security', value: 'max-age=63072000; includeSubDomains; preload' },
          {
            key: 'Content-Security-Policy',
            value: [
              "default-src 'self'",
              "script-src 'self' 'unsafe-eval' 'unsafe-inline' https://fonts.googleapis.com",
              "style-src 'self' 'unsafe-inline' https://fonts.googleapis.com",
              "font-src 'self' https://fonts.gstatic.com",
              "img-src 'self' data: blob:",
              "connect-src 'self' https://api.groq.com",
            ].join('; '),
          },
        ],
      },
    ];
  },
  compress: true,
  experimental: { optimizePackageImports: ['groq-sdk'] },
};
```

In `lib/rate-limiter.ts`, implement a **sliding window rate limiter** using `globalThis` singleton:
```typescript
// Store state on globalThis to persist across hot reloads
type RateLimitStore = Map<string, { count: number; resetAt: number }>;
const store: RateLimitStore =
  (globalThis as Record<string, unknown>).__rateLimitStore as RateLimitStore ??
  (() => {
    const m = new Map<string, { count: number; resetAt: number }>();
    (globalThis as Record<string, unknown>).__rateLimitStore = m;
    return m;
  })();

// Implement checkRateLimit(ip: string, endpoint: string, limit: number, windowMs: number)
// Returns: { allowed: boolean; remaining: number; resetAt: number; headers: Record<string, string> }
```

In all API route handlers:
- Validate body with Zod, return 400 on parse failure
- Extract IP from `x-forwarded-for` or `request.ip`
- Check rate limit BEFORE processing
- Never expose `GROQ_API_KEY` to client-side code
- Use `try/catch` with typed errors and return proper HTTP status codes

### 3. EFFICIENCY (Target: 100/100)
- Implement heuristic pre-classification (`lib/[domain]-classifier.ts`) using regex patterns to categorize input complexity BEFORE sending to LLM
- Route COMPLEX queries → `llama-3.3-70b-versatile`
- Route SIMPLE/FAST queries → `llama-3.1-8b-instant`
- Implement smart chunking (`lib/[domain]-chunker.ts`) for large inputs:
  - Estimate tokens: `Math.ceil(text.length / 4)`
  - Set max context: 6000 tokens (with 2000 buffer for response)
  - Truncate/chunk and process most relevant sections
- Use SSE (Server-Sent Events) for streaming responses — real-time output, no waiting
- Client-side file processing where possible (PDFs, text extraction) to reduce backend payload
- Implement `useMemo` and `useCallback` in React components where recomputation is expensive
